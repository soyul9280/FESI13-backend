> 🏝️ 같이 목표를 향해 달려갈 친구들은 어디서 찾지? 고민은 그만!
>
> 이 서비스는 스터디/프로젝트 모임을 개설하고 팀원들과 주간 Todo를 공유하며 달성률을 함께 관리하는 플랫폼입니다.
> 팀 달성률과 개인 달성률을 이용하여 목표 달성에 동기부여를 제공해요.

### 🏝️ 주요 기능


| 항목            | 상세 내용                                                             |
|---------------|-------------------------------------------------------------------|
| **모임 관리**     | - 모임 기본 CRUD <br/> - 상태 자동 전이 (RECRUITING → IN_PROGRESS → COMPLETED, 매일 자정 스케줄러)<br/>|
| **멤버 관리**     | - 호스트의 멤버 강퇴, 멤버 자진 탈퇴, 콕 찌르기                                               |
| **모임 신청 관리**     | - 신청·취소, 신청 수락·거절                                          |
| **즐겨찾기 관리**    | - 모임 좋아요·취소<br/>- 내 좋아요 목록·ID 목록 조회<br/>|
| **Todo 관리**     | - Todo 기본 CRUD<br/> - 현재 활성 주차만 작성 가능<br/>    |
| **달성률 관리**    | - 완료 Todo수 / 전체 Todo수 × 100, 소수점 1자리 반올림
| **리뷰 관리** | - 모임 완료 후 멤버 상호 리뷰<br/>- 태그 선택 방식 (성실해요·소통이 좋아요·도움이 돼요·시간 약속을 잘 지켜요·다시 만나고 싶어요)    |
| **알림 관리**    | - 8종 알림 (신청 받음·수락·거절·페널티 경고·모임 시작·모임 종료·리뷰 요청·콕 찌르기)<br/>- 이벤트 기반 자동 발송<br/>|
| **프로필 관리**    | - 회원가입<br/>- 사용자 프로필 수정<br/>|
| **인증 관리**     | - 로그인, 로그아웃<br/>|
